CYBR430 · Module 7

Windows SMB Exploitation & Password Analysis

Kali Linux · Metasploit · Meterpreter · John the Ripper

Project overview

In an instructor-authorized, isolated academic lab, assessed an MS17-010-vulnerable Windows host, established a Meterpreter session, retrieved local password hashes, and evaluated password weaknesses using John the Ripper.

Methods and observed results

Exploit selection and payload configuration; successful session; hash retrieval; password analysis.

Security considerations / lessons learned

Apply security updates, retire unsupported Windows systems, restrict SMB access, and strengthen password controls.
