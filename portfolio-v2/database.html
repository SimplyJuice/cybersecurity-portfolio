CYBR309 · Database Security

SQL Database Operations, Permissions & JSON

Three completed SQL Server assignments combined into a single case study: record manipulation, user permissions, and JSON data integration.

SQL ServerSSMST-SQLDCLOPENJSON

Methodology

  1. Insert, modify, remove and retrieve relational records.
  2. Create database accounts and assign SQL permissions.
  3. Import JSON-formatted data into relational tables.
  4. Generate JSON output and verify query results.
