CYBR430 · Penetration Testing

Windows SMB Exploitation & Credential Security

An authorized academic penetration-testing exercise examining the impact of MS17-010 on a vulnerable Windows host. The lab included exploit configuration, session establishment, and password-security analysis.

MetasploitMeterpreterJohn the RipperSMB

Methodology

  1. Identify the vulnerability and select the appropriate Metasploit module.
  2. Review module and payload configuration.
  3. Execute the authorized lab exercise and examine the terminal output.
  4. Analyze credential security and document mitigation steps.

Security takeaways

Patch vulnerable Windows systems, disable SMBv1 where feasible, restrict SMB access, and strengthen credential protections.
